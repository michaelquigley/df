The `(verb)(format)(layer)` grammar of `dd/io.go` takes a JSONL helper cleanly; a compact flag would sit on the shared `Options` struct where YAML silently ignores it, and would still leave the newline framing to every caller. Compact-without-newline JSON was not asked for — if it is, add the option then rather than trimming the JSONL suffix.

- Map key collision fix (`unbind-collapses-colliding-map-keys-nondeterministically`): the check in `valueToInterface`'s map case is universal, not gated on interface-keyed maps as the card assumed. Typed maps can collide too — `map[float64]V` holds multiple `NaN` keys that all stringify to `"NaN"`, and struct or array keys go through `%v` where a `String()` method can alias — and the check is one lookup in the result map already being filled, so gating it would cost more than it saves. The colliding keys are gathered by rescanning `MapKeys()` only on the error path and sorted before formatting, so the error text is itself deterministic; the happy path pays nothing.
- Deliberate non-action: a collision inside a nested map value (`map[string]map[any]V`) still surfaces without the outer key in its path. `Unbind` threads no path the way `Bind` does (`path[key]`); the wrapping `UnbindingError` names the struct field, and the error names the colliding spelling and both key types, which is enough to find it. Path threading for unbind is its own change.

# 2026-09-01

- JSONL output landed as a named helper pair (`UnbindJSONL`, `UnbindJSONLWriter`) rather than an `Options.Compact` knob. The `(verb)(format)(layer)` grammar of `dd/io.go` takes a JSONL helper cleanly; a compact flag would sit on the shared `Options` struct where YAML silently ignores it, and would still leave the newline framing to every caller. Compact-without-newline JSON was not asked for — if it is, add the option then rather than trimming the JSONL suffix.
- No `UnbindJSONLFile`: a whole-file write of one record is the wrong shape for an append-only format. Callers open with `O_APPEND` and use the writer variant; example `dd_04_io` step 4 shows the pattern.
- No JSONL intake helper: `bufio.Scanner` + `BindJSON` per line already covers reading, and the godoc says so. Revisit only if a consumer asks.

## AGENTS.md is the only agent guidance file

`CLAUDE.md` was removed on purpose in a practice-wide sweep; don't recreate it, as a file or as a symlink. Claude Code (verified on 2.1.278) loads `AGENTS.md` when no `CLAUDE.md` exists, walking up from the working directory the same way. When both exist it loads only `CLAUDE.md` and never sees `AGENTS.md` — so a second file is not a harmless alias, it's the one that wins and then goes stale. The same sweep added the stock project-memory and commit-gate paragraphs to `AGENTS.md`.
